Обновление Mortal Kombat 3 Ultimate — 04.11.2026

Установка:
1. Распакуйте архив. Внутри папки games и relay.
2. В корне john-toloknov/INTERNET_INSTALLER: Add file → Upload files.
3. Перетащите обе папки games и relay целиком, затем Commit changes.
   Совпадающие файлы обновятся. Папки на GitHub предварительно НЕ удаляйте.
   Не загружайте ZIP вместо распакованных папок. Не помещайте games внутрь games.
4. Дождитесь успешного обновления GitHub Pages и сервиса Render.
   Если автообновление Render выключено: Manual Deploy → Deploy latest commit.
5. Оба игрока закрывают старую игру и обновляют сайт Ctrl+F5.
   Затем создают новое приглашение и открывают матч.

Основной фронтенд, Ежедневный и Apps Script для этой правки менять не требуется.
Адрес Render, секрет и остальные переменные окружения сохраняются прежними.

Что изменено:
- Видео, звук и управление передаются напрямую между браузерами, когда сеть позволяет.
- Если прямой путь недоступен, автоматически остается передача через Render.
- Звук берется с общего микшера игры: переключение внутренних каналов его не отсоединяет.
- Захват звука работает в AudioWorklet, с запасным ScriptProcessor для старых браузеров.
- Клавиатура работает и при фокусе на основной странице, и внутри экрана игры.
- Пользовательская раскладка сохранена. Текстовая справка об управлении не возвращена.
- Звук включается при нажатии игровой клавиши или экранной кнопки.
  Если браузер заблокировал звук, доступна кнопка 🔊.
- Сворачивание игры любым участником по-прежнему приостанавливает сетевой матч.

Проверка типа соединения: над игрой появится «Прямое соединение» или «Через сервер».
Закрытые корпоративные сети могут блокировать прямой путь. При передаче через сервер
задержка зависит от его расположения и качества интернета; отсутствие лагов во всех
сетях не гарантируется. Платные серверы и TURN в этой версии не требуются.

Проверено локально: настоящая игра в двух браузерных контекстах, непрерывные слышимые
аудиосэмплы у второго игрока, сочетания клавиш, цифровой блок, разделение портов
в режиме «Двое рядом», резервный поток, сворачивание/возобновление и переподключение.
Проверены подписи сессий, разделение комнат, запрет чужого Origin и просроченных токенов.
Проверка в вашей рабочей сети после установки остается необходимой.
